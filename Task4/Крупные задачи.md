- **Автоматический экспорт** — после сохранения ставок запускается экспорт (можно через Kafka event или cron).

| **Альтернатива**                    | **Обоснование отказа / выбора**                                                |
|-------------------------------------|--------------------------------------------------------------------------------|

| **Размещение файла на веб-сервере** | Рассматривалось, но SFTP надёжнее и соответствует политике безопасности банка. |

### **Недостатки, ограничения, риски**

| **Аспект**                                | **Описание**                                                                                             |
|-------------------------------------------|----------------------------------------------------------------------------------------------------------|
| **Задержка в данных для партнёра**        | Если SFTP недоступен — задержка до следующего цикла. Решение: мониторинг + retry.                        |
| **Ошибка парсинга файла**                 | Партнёр может неправильно прочитать CSV. Решение: чёткая документация + примеры.                         |
| **Отсутствие обратной связи от партнёра** | Мы не знаем, получил ли он файл. Решение: договориться о подтверждении получения (например, .done-файл). |
| **Ограниченная гибкость формата**         | При изменении структуры нужно согласование. Решение: версионирование API и файлов.                       |
| **Зависимость от SFTP-инфраструктуры**    | Требует настройки и поддержки. Решение: использовать существующий корпоративный SFTP.                    |
